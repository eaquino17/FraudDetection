# Fraud Detection Project

This repository contains the code and documentation for a fraud detection project. The goal of this project is to build a machine learning model capable of identifying fraudulent credit card transactions.

## Overview

The project utilizes a dataset of credit card transactions to train a classification model. The provided Python code demonstrates the initial steps in this process, including:

- **Data Loading and Exploration:** Loading the credit card transaction data using pandas.
- **Data Preprocessing:** Preparing the data for model training, including potential scaling or feature engineering (though not explicitly shown in the snippet).
- **Model Selection:** Choosing a Random Forest Classifier as the initial model.
- **Model Training and Evaluation:** Splitting the data into training and testing sets, training the model, and evaluating its performance using metrics like confusion matrix, classification report, and ROC curve.
- **Visualization:** Using seaborn and matplotlib for data visualization and model evaluation.


To run this project, you will need to have Python installed on your system along with the following libraries:

- pandas
- numpy
- scikit-learn
- seaborn
- matplotlib
